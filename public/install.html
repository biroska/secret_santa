SecretSanta

Para participar do seu Amigo Secreto, instale o aplicativo SecretSanta. Depois de instalar, abra novamente o link do convite que você recebeu.

Baixar SecretSanta (APK)
  1. Toque em "Baixar SecretSanta (APK)" acima.
  2. Se o Android pedir permissão para instalar apps de fontes desconhecidas, toque em "Configurações" e permita a instalação para o seu navegador.
  3. Abra o arquivo baixado para instalar o app.
  4. Após instalar, toque novamente no link do convite que você recebeu.
